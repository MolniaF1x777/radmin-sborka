# Сборка для игры через Radmin VPN

Всем привет. Это готовая сборки для удобной игры и настройки сети через Radmin VPN. Всё уже оптимизировано, батники чистые и проверенные, компьютер ругаться не будет.

## Что внутри:
* Всё настроено: скачал и сразу пользуешься
* Без вирусов: код в батниках открытый, можете сами проверить

## Как запустить:
1. Зайди в раздел **Releases** справа и скачай `.zip` архив.
2. Распакуй весь архив в любую папку.
3. Запусти главный `.bat` файл.
4. Включай Radmin VPN и запускай игру или подключение.
